# 找到有 Wwise 的电脑后怎么检查

这一步需要 Wwise 2025.1.11.9262。只播放试听 WAV 不需要安装 Wwise。此包的 Wwise 工程由脚本创建，尚未通过软件打开验证；下面的参数既是验收目标，也是载入时某项未保留时的修正参考。

## 打开工程

1. 完整解压 KinmenCoastalRoad_Final.zip；推荐放到英文路径，例如 D:/AudioWork/KinmenCoastalRoad_Final。
2. 启动指定版本 Wwise，选择 Open Existing Project，打开 Wwise/KinmenCoastalRoad/KinmenCoastalRoad.wproj。
3. 如提示工程损坏或不识别属性，保留提示截图与原始文件，不要直接覆盖原包。本包的文件检查无法排除这些兼容问题。
4. 确认 Containers 下有风声、RC_Vehicle_Pass 和 RC_Birds_Sparse；车辆下有 4 个 Sound，鸟声下有 2 个。若出现 Missing Audio，先检查 Originals/SFX 的七个 WAV 是否随文件夹一起解压。
5. 选择 Windows 平台、正常的系统音频输出；等待音源转换完成。

## 播放验收

打开 Soundcaster 布局，载入 Soundcaster Sessions 中的 SC_KinmenCoastalRoad。

| 操作 | 预期 |
|---|---|
| 单击 Play_KinmenCoastalRoad 一次 | 风声开始，约 8 秒后第一次鸟声、15 秒后第一次车声 |
| 连续播放至少 3 分钟 | 风声越过 60 秒边界仍连续；车辆与鸟声分别随机出现 |
| 观察车辆容器 | 4 个文件会轮换随机选择，不连续重复；上一段结束后间隔 18–32 秒 |
| 观察鸟声容器 | 间隔 12–22 秒；不要过分突出或形成持续合唱 |
| 检查每个车辆 Sound 的 Positioning | Override Parent、3D、Listener Relative Automation；路径时长和素材相同 |
| 播放单个车辆并观察路径 | 经过最近点时更清晰响亮，远端较轻；没有左右跳变或尾部被突然切断 |
| 打开 Attenuations | 有 ATT_Vehicles_120m 和 ATT_Birds_40m，音量与低通曲线均已关联 |
| 点击 Stop_KinmenCoastalRoad | 三层在约 1 秒内停止，不再自动启动 |

不要多次点击总播放来测试，否则可能叠加多个随机系统。需要重听时先停止，等声音全部结束后再开始。独立试听层时也先停掉总播放。

如果参数与预期不同，按以下目标修正后保存：车辆和鸟声容器均为 Random / Continuous / Loop Infinite / Avoid repeating last 1 / Transitions: Delay；车辆 Delay=25 s，随机 Min=-7、Max=7；鸟声 Delay=17 s，随机 Min=-5、Max=5。风声 Sound 为 Loop / Infinite。详细路径和曲线见声音设计说明及 Source/wwise_design.json。

## 检查留档

在 Docs/Wwise验收记录.txt 中填写实际软件版本、日期和结果。建议保留工程总览、随机容器设置、Positioning/衰减和 Soundcaster 的截图，便于说明作品；老师原文未强制要求截图或视频。

通过检查后保存工程，将本文件夹内容上传到公开 GitHub 仓库，保留 .gitignore。不必将外层 ZIP 再上传到仓库。仓库必须包含 Wwise 工程、Work Unit、Originals 和声音资产，不能仅上传 .wproj 或试听混音。

邮件模板位于 Docs/邮件模板.txt，填写姓名、学号和仓库链接后再发送。此包未执行 GitHub 上传或邮件发送。

## 可编辑文件

Reaper/AssetProjects 中七个工程对应七份资产，媒体路径为相对路径。Reaper/KinmenCoastalRoad_Mix.rpp 是两分钟试听编排。需要重导出时使用 48 kHz、24 bit PCM、Stereo；改动 WAV 后同步替换 Wwise/Originals/SFX 中同名文件。

Tools/validate_project.py 是可选的只读文件检查工具，需要 Python 3.12+。不运行它也能直接打开 Wwise。Tools/render_assets.lua 可在 REAPER 中重新渲染七个资产，但会覆盖同名 WAV；重新渲染后应同步 Originals 并重新检查。
