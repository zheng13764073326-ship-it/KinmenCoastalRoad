# 弯道望海 · 金门：声音设计说明

## 画面与场景设定

画面是本人在金门旅行时拍摄的一段临海道路。两侧树木在前景形成阴影，路面向前延伸后转弯；中景有路标和低层建筑，海面在远处露出。听者固定在拍摄位置附近的树荫路边。

作品设定为白天、交通稀疏的道路。持续风声连接整个空间，偶尔经过的车辆形成接近、掠过、远去的动态，鸟声放在两侧树木方向。这是根据画面设计的声景，不声称还原照片拍摄时的真实声音，也不推断鸟的物种、具体景点或拍摄季节。

## 声音资产

| 文件（省略 .wav） | 时长 | 作用与处理 |
|---|---:|---|
| AMB_Kinmen_Roadside_Wind_Loop | 60 秒 | 风与树叶连续底声；比旧版降低 3 dB，2 秒交叉淡化衔接 |
| SFX_Vehicle_Pass_01 | 7.4 秒 | 第一种汽车经过；保留自然接近和离去动态 |
| SFX_Vehicle_Pass_02 | 11.8 秒 | 第二种汽车经过；音色与第一种不同 |
| SFX_Vehicle_Pass_03 | 12 秒 | 第一种机车经过；保留原录音的音调变化 |
| SFX_Vehicle_Pass_04 | 12 秒 | 第二种机车经过；截取主体，末尾较长淡出 |
| SFX_Bird_Sparse_01 | 2.8 秒 | 短鸟鸣；相对旧版峰值降低 8 dB |
| SFX_Bird_Sparse_02 | 3 秒 | 另一种短鸟鸣；稀疏出现 |

全部资产为 48 kHz、24 bit、双声道 PCM WAV。源素材经过滤波、去直流和必要的重采样后，在 REAPER 中剪辑、淡化、调整增益并导出。四个车辆资产来自四份不同录音，不是同一个文件改名。

车辆素材已归中，使用左右相同的双声道文件，避免原录音的左右移动与 Wwise 位置自动化冲突。树风保留立体声宽度。原始 MP3 与预处理 WAV 均保留，可重新调整剪辑。

## Wwise 结构与参数

- 工程：KinmenCoastalRoad，目标版本 2025.1.11.9262，Windows 平台。
- 环境声：无限循环、2D 声床。
- RC_Vehicle_Pass：四个子声音；Random，避免连续重复 1 个；Continuous + 无限 Loop；Delay 为 25 秒，随机偏移 ±7 秒，即片段结束后等待 18–32 秒。
- RC_Birds_Sparse：两个子声音；同样避免连续重复；Delay 为 17 秒，随机偏移 ±5 秒，即结束后等待 12–22 秒。
- 单次启动时，车辆采用顺序等待而非交叉叠加，正常情况下同一时刻只有一辆。请不要反复点击 Play 叠加启动。
- 主事件启动后：风声立即播放并淡入 1 秒，鸟声延迟 8 秒，车辆延迟 15 秒。Stop 事件对三层声音淡出 1 秒。

车辆的 Positioning 写在四个 Sound 上。每段采用 Listener Relative Automation；路径时长分别匹配 7.4、11.8、12、12 秒。起点或终点在左前方弯道 (-45,70)，另一端在右后侧 (24,-95)，最近点为 (8,3)，距离约 8.5 米；第二、四段反向经过。最近时刻对应各素材主峰附近：1.5、3.4、3.6、5.25 秒。

ATT_Vehicles_120m 的音量点为 0 m / 0 dB、12 m / 0 dB、40 m / -4 dB、80 m / -10 dB、120 m / -32 dB。低通随距离从 0 增加到 35。录音自身已有远近动态，因此额外衰减较缓，不再添加人工 Doppler。

鸟声在四个静止位置随机选择：(-4,5)、(7,6)、(-13,17)、(18,22)。ATT_Birds_40m 从近处 0 dB 逐渐降到 40 m / -40 dB，远处低通最高 35。坐标单位为工程中的距离单位；按米解释是本作业的设计约定。

声音经 Ambience、Vehicles、Birds 三条总线汇入 Main Audio Bus，再送入 System 输出设备。Soundcaster Session 为 SC_KinmenCoastalRoad，含总播放、总停止和三层独立播放事件。

## 两分钟试听混音

混音为 REAPER 固定编排：车辆在 15、45、77、108 秒出现，四种素材各出现一次；鸟鸣在 8、29、52、72、96、113 秒出现。底声连续播放 120 秒，开头 2 秒淡入、末尾 3 秒淡出。

混音用 REAPER 声像和音量包络近似表达 Wwise 路径，未模拟 Wwise 的低通曲线，也不是 Wwise 录制结果。它用于听整体节奏；随机顺序和距离响应最终应在 Wwise 中验收。

## 取舍与待确认项

不加入贴耳海浪、海鸥、喇叭或人群。海在画面里属于远景，不能仅凭能看见海就假定路边能听见很响的浪声。音效库录音并非金门实录，声音和照片的结合属于设计。

Wwise 工程由脚本写出，XML 结构与引用可检查，但软件兼容、随机间隔、定位方向和实际听感尚待在指定版本中确认。若试听发现车声过急、鸟声太亮或某段带有不合适背景，应回到对应 REAPER 工程调整；不把数字检查当作听感评价。
