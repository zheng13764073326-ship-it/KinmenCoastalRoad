#弯道望海 · 金门

以本人在金门旅行时拍摄的照片为设计对象：听者站在树荫路边，前方是一段弯道和低层建筑，远处可以看见海。持续的风树声、间歇驶过的汽车与机车、稀疏的鸟鸣构成声音场景。照片为本人拍摄。

## 文件状态

七个正式 WAV 资产和可编辑 REAPER 工程已制作；Wwise 工程已写入循环、随机容器、定位路径、衰减、事件和 Soundcaster Session。
